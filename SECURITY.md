# Security policy

## Supported versions

Security fixes go into the latest release. Upgrade to it before reporting, if you can.

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub: open the repository's **Security** tab and click **Report a vulnerability** ([direct link](https://github.com/septi0/dockvmap/security/advisories/new)). Don't open a public issue.

Include the DockVMap version, what an attacker can do, and the steps to reproduce it. You'll get an answer as soon as possible, and credit in the release notes if you want it.
